Watch Later

Browse and edit your YouTube watch-later list stored in watch_later.json. Changes are written back to that file as you go.

Before you start

  1. Open this page at http://localhost:… or http://127.0.0.1:… (Live Server, python -m http.server, Netlify, etc.). It does not work from file:// or http://0.0.0.0:… in Chrome.
  2. Use a Chromium browser (Chrome or Edge) so the file picker and save API are available.

Then

  1. Click Open watch_later.json below and choose your JSON file. The app stores a bookmark to that file in the browser so it can reconnect after a refresh (for example when Live Server reloads the page because the JSON was saved).
  2. Video lengths stay empty until you run python3 fetch_durations.py on your machine (you can copy that command from Menu after loading).

If the button does nothing or errors, check the address bar: it should start with http://localhost or http://127.0.0.1, not file:// or 0.0.0.0.

Your previous file is saved in this browser, but Chrome needs you to allow access again after a full page reload (for example when Live Server refreshes because the JSON changed).

Instructions & shortcuts

Saving

This app displays and edits a JSON file on your computer. Use Menu → Open JSON file to switch files; Menu → Help & shortcuts opens this guide.
  • Add video — Paste a YouTube link and fetch its title, optionally pick a category, then add. Enter always confirms.
  • Menu → Import JSON and overwrite — Replaces the current list with a new JSON file.
  • Menu → Merge from JSON — Adds videos from a JSON file; entries that match a video already in the list (same YouTube id) are skipped.
  • Menu → Export — Download your list as JSON or CSV, or copy the duration-fetch command.

Browsing

Filter by search, category, watched status, or duration. The yellow badge counts unwatched videos.
  • Click a card to open it on YouTube.
  • Click a category tag to filter by it; click Uncategorized to assign a category.
  • Active filters show as pills — click one to remove it, or use Remove filters to clear all.
  • Time budget — Dropdown next to sort: from the current filters and sort order, pick videos whose lengths add up to about the target (skips videos that would overshoot by more than a few minutes, then keeps going). Shown as a pill while active.

Batch Mode

Right-click or long-press a card to select it, then click more cards to add to the selection. Use Edit duration when exactly one card is selected. Press Esc to exit.

Keyboard

  • N — Add video
  • F — Focus search
